# سهل السفر — Easy Travel

ثيم Salla Twilight لوكالة سهل السفر للسفر والسياحة. يعرض الرحلات والباقات دون أسعار، ويتم الحجز عبر واتساب، ثم يُرسل رابط الدفع من سلة إلى العميل في رسالة نصية بعد الاتفاق.

## التطوير

يتطلب Node.js `22.18+` أو `24.11+` وpnpm وSalla CLI:

```sh
pnpm install
pnpm run development
salla theme preview
```

لإنشاء ملفات الإنتاج: `pnpm run production`.

## أين أعدّل؟

| ماذا | أين |
|---|---|
| واتساب، الهاتف، البريد، السجل التجاري، حسابات التواصل، رابط فيديو بديل | لوحة سلة ← إعدادات الثيم ← بيانات الوكالة (`twilight.json`) |
| ألوان الهوية وأنماط الوكالة | `src/assets/styles/easy-travel.css` |
| نصوص الصفحة الرئيسية وبطاقات الوجهات | `src/views/pages/index.twig` |
| الشعار والأيقونة | `src/assets/images/` |
| فيديو أعلى الصفحة | `src/assets/videos/hero.mp4` |
| نصوص زر الحجز ورسالة واتساب | `src/locales/ar.json` و`en.json` |

## آلية الحجز

- لا تظهر الأسعار ولا زر الإضافة للسلة في البطاقات وصفحة الرحلة والبحث والمفضلة.
- زر «احجز عبر واتساب» يفتح رسالة جاهزة فيها اسم الرحلة ورابطها.
- صفحات السلة والدفع والطلبات والفواتير تبقى كما هي، لأن رابط الدفع من سلة وسجل طلبات العميل يعتمدان عليها.

## هيكل المستودع

| المسار | المحتوى |
|---|---|
| `src/` | قوالب الثيم وأنماطه ونصوصه |
| `public/` | ملفات البناء التي يستخدمها المتجر |
| `twilight.json` | تعريف الثيم وإعداداته |
| `prototype/` | النموذج التفاعلي القديم وملفات الهوية الأصلية، للرجوع إليها فقط وهي ليست جزءًا من الثيم |
