# سهل السفر — Easy Travel

نموذج تفاعلي كامل لمتجر رحلات سياحية على **سلة**، يُعتمد شكله وتفاعله ثم يُحوَّل إلى ثيم Salla Twilight.

## التشغيل
افتح `index.html` في المتصفح مباشرة، دون أي أدوات بناء.
- لإعادة تشغيل شاشة الافتتاح: `index.html?intro`
- تظهر الافتتاحية مرة واحدة في كل جلسة، ولا تظهر إذا فعّل الزائر خيار «تقليل الحركة» في جهازه.

## أين أعدّل؟
| ماذا | أين |
|---|---|
| رقم الواتساب | `assets/js/data.js` ← `WHATSAPP_NUMBER` |
| الباقات والرحلات (الأسعار، البرنامج، ما تشمله) | `assets/js/data.js` ← `PRODUCTS` |
| التصنيفات | `assets/js/data.js` ← `CATEGORIES` |
| آراء العملاء | `assets/js/data.js` ← `TESTIMONIALS` |
| الألوان والخطوط | `assets/css/style.css` ← `:root` |
| أرقام لوحة المغادرة | `index.html` ← `data-text` في `.board` |

## الصفحات
| الملف | الصفحة | المقابل في ثيم سلة (Twilight) |
|---|---|---|
| `index.html` | الرئيسية | `src/views/pages/index.twig` |
| `packages.html` | الباقات والرحلات | `src/views/pages/product/index.twig` |
| `product.html?id=…` | صفحة الباقة أو الرحلة | `src/views/pages/product/single.twig` |
| `cart.html` | السلة | `src/views/pages/cart.twig` |
| `login.html` | الدخول برمز التحقق | نافذة `salla-login-modal` المدمجة في سلة |
| `account.html` | حسابي، طلباتي، المفضلة | `src/views/pages/customer/*.twig` |
| `thank-you.html` | تأكيد الطلب | `src/views/pages/thank-you.twig` |
| `about.html` · `guarantee.html` · `contact.html` | صفحات تعريفية | `src/views/pages/page-single.twig` (صفحات مخصصة) |
| `404.html` | صفحة غير موجودة | صفحة الخطأ في الثيم |

## ما يعمل محلياً للتجربة فقط
السلة والمفضلة والدخول والطلبات تُحفظ في متصفح الزائر (`localStorage`) لعرض التجربة كاملة. عند التحويل إلى سلة تُستبدل كلها بمكونات سلة الحقيقية: السلة والدفع والحساب والطلبات وكوبونات الخصم.
- كود الخصم التجريبي: `SAHL10` (خصم 10%).
- رمز التحقق التجريبي: أي 4 أرقام.

## محتوى يجب مراجعته قبل النشر
- **الأسعار** في `data.js` تجريبية.
- **أرقام لوحة المغادرة** (+4800 مسافر، 98% رضا…) أمثلة، وتُستبدل بأرقام حقيقية أو تُحذف.
- **آراء العملاء** أمثلة، وتُستبدل بآراء حقيقية.
- **نصوص الضمان وسياسة الإلغاء** صياغة عامة، وتُراجع لتطابق سياستكم الفعلية.
- **أوقات الرد** في صفحة التواصل.
- الصور من Unsplash (مجانية للاستخدام التجاري)، ويُفضّل لاحقاً رفعها إلى مكتبة صور سلة.
