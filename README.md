# سهل السفر — Easy Travel

ثيم سلة بتقنية React لوكالة سهل السفر للسفر والسياحة. يعرض الرحلات والباقات بدون أسعار، ويتم الحجز مباشرة عبر واتساب.

مبني على محرك ثيمات سلة `@salla.sa/twilight-theme-engine` (TanStack Start).

## ما يميز الثيم

- **الصفحة الرئيسية:** فيديو تعريفي، شاشة تحميل وافتتاحية متحركة، نموذج «خطط رحلتك» يرسل الطلب على واتساب، شريطان متحركان، سلايدر الوجهات، الباقات بتصميم بطاقات صعود الطائرة، «من الفكرة إلى الإقلاع» بطائرة ترسم مسارها، لوحة مغادرة، آراء العملاء كبطاقات بريدية، معرض صور، وصندوق حجز.
- **الحجز عبر واتساب:** في بطاقات المنتجات وصفحة الرحلة، برسالة جاهزة فيها اسم الرحلة ورابطها.
- **الهيدر:** يختفي عند النزول ويعود عند الصعود، وقائمة كاملة الشاشة لكل المقاسات من قائمة المتجر في سلة.
- **إعدادات الوكالة:** رقم واتساب، الجوال، البريد، السجل التجاري، الحسابات الاجتماعية، وأرقام لوحة المغادرة، كلها من إعدادات الثيم.

## أين الملفات

| المسار | المحتوى |
|---|---|
| `app/components/etx/` | مكونات سهل السفر: الهيدر، الفوتر، الصفحة الرئيسية، الافتتاحية، الحجز |
| `app/lib/easyTravel.ts` | بيانات الوكالة وروابط واتساب |
| `app/styles/04-components/easy-travel.scss` | أنماط الهوية والتصميم |
| `app/assets/` | الشعار والفيديو والصور والخط الزخرفي |
| `twilight.json` | إعدادات الثيم وعناصر الصفحة الرئيسية |
| `docs/help.md` | دليل استخدام الثيم للتاجر |

## التطوير

```bash
pnpm install
salla theme dev      # المتجر على http://localhost:5173/ar
pnpm build
pnpm typecheck
pnpm test
pnpm check:manifest  # بعد تعديل twilight.json
```

تحتاج Windows إلى Microsoft Visual C++ Redistributable لتشغيل `salla theme dev`.
